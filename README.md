# 记忆档案馆

治愈系个人记忆存档网页交互作品，使用 HTML、CSS 和 JavaScript 构建。

## 在线演示

发布后通过本仓库的 GitHub Pages 地址访问。首页入口为 `index.html`，界面导航使用 URL hash。

## 体验说明

- 记忆、资料和会话数据保存在访问者当前浏览器中，不会跨设备同步。
- 登录、注册及 AI 相关功能属于交互演示，并非正式账户认证或在线 AI 服务。
- 网页展示与本地原版保持一致，所有资源均使用相对路径。

## 发布配置

在仓库 Settings → Pages 中选择 Deploy from a branch，选择 main 分支与 / (root) 目录。
